# Career-Built - Job Portal Website

A frontend prototype of a job portal where users can login, upload resume, search and apply for jobs across different domains.

## About The Project
This is a career building website prototype built with only HTML. It allows users to choose from 6 different job fields and apply for jobs in various companies and sectors.

## Features
- User Login & Registration UI
- Upload Resume Option
- Search Jobs by Field
- 6 Job Categories: Marketing, Automobile, Admin, Design, Finance, sales
- View Companies by Sector
- Apply for Job Feature
- Responsive Frontend Design

## Tech Stack
- HTML (98%)
- CSS
- VS Code
- Git & GitHub

## Project Status
Frontend Prototype Completed - Backend Integration Pending
